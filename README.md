## 🧩 Sobre este projeto

Este repositório guarda o meu **currículo online**: uma página web estática, feita com HTML, CSS e um pouco de JavaScript, sem frameworks e sem etapa de build.

### ✨ Funcionalidades

- 📄 **Layout A4** pronto para impressão, que vira um PDF de uma página com texto selecionável, que as plataformas de vagas (ATS) conseguem ler.
- 📱 **Responsivo:** se adapta a celulares e tablets.
- ⬇️ **Botão "Baixar PDF"** com a versão oficial do currículo.
- 🖨️ **Botão "Gerar PDF pelo navegador"**, para gerar o PDF na hora a partir da página.
- 🙈 **Mostrar ou ocultar a foto**, para vagas que pedem currículo sem foto. A escolha fica salva no navegador.
- 🔎 **SEO e prévia social:** título, descrição e Open Graph para gerar um card com foto ao compartilhar o link.
- 🚀 **Deploy automático** no GitHub Pages via GitHub Actions a cada `push` na branch `main`.

### 🗂️ Estrutura

```
curriculo/
├── index.html                          # Página do currículo (HTML + CSS + JS)
├── assets/
│   ├── Curriculo-Joao-Claudio-Dias.pdf # Versão em PDF (1 página)
│   └── foto-perfil.jpg                 # Foto de perfil
├── .github/
│   └── workflows/
│       └── pages.yml                   # Publicação no GitHub Pages
└── README.md
```

### 💻 Como rodar localmente

```bash
git clone https://github.com/joaodias3ds/curriculo.git
cd curriculo
```

Depois, abra o `index.html` no navegador com dois cliques. Não é preciso instalar nada.

### 🔄 Como atualizar

1. Edite o conteúdo no `index.html`.
2. Para gerar o PDF, abra a página no Chrome ou no Edge, clique em **Gerar PDF pelo navegador** e escolha **Salvar como PDF**, com **Margens: Nenhuma** e **Gráficos de fundo** ligado.
3. Substitua o arquivo `assets/Curriculo-Joao-Claudio-Dias.pdf`.
4. Envie as mudanças:

```bash
git add .
git commit -m "Atualiza currículo"
git push
```

Em cerca de 1 minuto, o site em **https://joaodias3ds.github.io/curriculo/** é atualizado sozinho.
